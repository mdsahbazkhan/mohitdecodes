## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/mdsahbazkhan/mohitdecodes.git

cd mohitdecodes
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Visit:

```
http://localhost:3000
```

---

## 📦 Production Build

```bash
npm run build
npm run start
```
